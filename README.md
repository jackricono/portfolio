# Jack Riconosciuto — Portfolio

Astro portfolio for `riconosciuto.net`.

## Local development

Install dependencies and run:

```bash
npm install
npm run dev
```

Build with:

```bash
npm run build
```

## Deployment

The site is configured for GitHub Pages with GitHub Actions and the custom domain `riconosciuto.net`.

The domain is represented by `public/CNAME`, and `astro.config.mjs` uses `https://riconosciuto.net` as the site URL.
